# CCA 3 - Computer Vision Assignment

## Overview
This repository implements image restoration, segmentation, feature extraction,
object recognition, and motion estimation tasks using OpenCV, scikit-image, and YOLO.

## Folder Structure
- data/ - input photo and video (large video linked via Google Drive)
- src/ - source code for Task 1-4
- outputs/ - generated results

## How to Run
1. pip install -r requirements.txt
2. Place input photo/video in data/ folder
3. Run each script:
   python src/task1_restoration_segmentation.py
   python src/task2_feature_matching.py
   python src/task3_object_recognition.py
   python src/task4_motion_estimation.py
